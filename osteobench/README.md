# OsteoBench

A 68-question, execution-scored benchmark for evaluating tool-using agents on SR-microCT bone image analysis workflows for osteoporosis research.

This benchmark accompanies the paper *"A Multi Agent AI Assistant for Osteoporosis Research at the Bone Microscale"*, accepted at the ECCV 2026 BioImage Computing workshop.

## Files

| File | # questions | Covers |
|---|---|---|
| `data_qa.json` | 10 | Data inspection |
| `preprocessing_qa.json` | 8 | Preprocessing |
| `segmentation_qa.json` | 10 | Segmentation |
| `phenotyping_qa.json` | 25 | Morphometry & Classification |
| `statistics_qa.json` | 15 | Segmentation evaluation & Classification leave-one-out |
